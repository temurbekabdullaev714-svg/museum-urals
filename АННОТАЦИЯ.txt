1. НАЗВАНИЕ И НАЗНАЧЕНИЕ
=====================================================================

Название сайта: «Музей Южного Урала — виртуальный путеводитель»
Тема: Государственный исторический музей Южного Урала, город Челябинск.

Назначение: интерактивный путеводитель по постоянной экспозиции музея.
Сайт помогает спланировать визит заранее: познакомиться с тремя залами,
главными экспонатами и историей музея, а затем проверить себя коротким
квизом. Аудитория: посетители музея, школьники и студенты, участники
областного конкурса, все, кому интересна история Челябинска.

3. ТРЕБОВАНИЯ К ПРОГРАММНОМУ ОБЕСПЕЧЕНИЮ СЕРВЕРА
=====================================================================

Сайт размещён на хостинге GitHub Pages (HTTPS), адрес сайта:
https://temurbekabdullaev714-svg.github.io/museum-urals/

Сайт статический. Серверные языки и технологии (PHP, Python, JSP и т.п.)
не используются, серверной обработки нет.

Для проверки работы:
  - современный браузер (Chrome, Firefox, Edge, Safari) с включённым
    JavaScript;
  - любой статический веб-сервер, отдающий файлы по HTTP/HTTPS.

Локальный запуск (пример для Python 3):
  1. Распаковать архив в любую папку.
  2. Открыть командную строку в папке с index.html.
  3. Выполнить:  python -m http.server 8000
  4. Открыть в браузере:  http://localhost:8000/

Возможен и простой запуск двойным кликом по index.html — сайт
работает и без HTTP-сервера, однако для корректной проверки
рекомендуется HTTP-сервер.

Размещение в Интернете: подойдёт любой хостинг статических сайтов
(Nginx, Apache, GitHub Pages, Timeweb, Beget и аналогичные), который
отдаёт HTML, CSS, JavaScript и каталог assets. Рекомендуется HTTPS.
Дополнительных модулей, расширений и БД не требуется.

6. АВТОРСТВО
=====================================================================

Тексты сайта — авторская подготовка команды из трёх участников
по материалам официального сайта Государственного исторического
музея Южного Урала (chelmuseum.ru).

Графика:
  - схема маршрута по залам, логотип проекта и элементы
    интерфейса — нарисованы авторами проекта (HTML/SVG/CSS);
  - фотографии — Wikimedia Commons, лицензии CC0 и CC BY-SA;
    авторы указаны в разделе «Источники» на главной странице
    и в файле ИСТОЧНИКИ.md;
  - шрифты Unbounded и Manrope — Google Fonts, SIL Open Font
    License 1.1, локальные копии в assets/fonts (текст лицензии
    в assets/fonts/OFL.txt).

Музыкальные фрагменты на сайте не используются.
Видеофрагменты на сайте не используются.
